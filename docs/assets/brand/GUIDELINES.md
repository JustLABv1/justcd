# JustCD logo guidelines

**Idea:** an open ring (the cluster, continuously reconciled) with one green dot (the commit) landing in its gap.

| | |
|---|---|
| Ink | `#1F2024` (on dark: `#F5F5F5`) |
| Accent (dot only) | `#2454D6 (app primary; #8AAAFF on dark)` |
| Files | `symbol.svg` (default), `symbol-small.svg` (under 24 px), `horizontal*.svg`, `stacked.svg`, `*-black/white.svg` (one colour) |
| Clear space | One ring-stroke width ×2 (about 1/4 of the symbol height) on all sides |
| Minimum size | Symbol 16 px (use `symbol-small.svg` below 24 px), horizontal lockup 96 px wide |
| One-colour | Dot takes the ink colour; never recolour the dot to another hue |
| Don't | Rotate, close the gap, add effects/gradients, move the dot, or restyle the wordmark |

Note: the wordmark is built from monoline strokes (not outlined paths); outline it in a vector editor before print production.
